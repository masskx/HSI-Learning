HSI-Learning 录课讲稿 · 使用说明
================================================================

这个文件夹里是 12 节课的逐页讲稿（L00、L01、L02、L03、L04、L05A、L05、L06、L07、L08、L09、L10），
每课一个 TXT，可以直接打印放在手边，边看边讲。

讲稿里的标记
----------------------------------------------------------------
  ▶ 第 N 页              PPT 第几页（与 slides/decks/ 里的课件页码一致）
  【画面】               这一页屏幕上有什么，方便你对照
  【讲】                 建议的口播原文，可以照念，也可以换成自己的话
  【操作】               你要做的动作：翻页、切窗口、运行 cell、改代码
  【停顿】               留 2～3 秒给观众思考，可以说“可以先暂停视频想一想”
  【屏幕上应看到】       运行 cell 后的预期输出（来自你电脑上已执行的 Notebook）
  【如果不一样】         输出和讲稿不一致时怎么处理
  （约 X 分钟）          这一段的建议时长

每课的固定流程
----------------------------------------------------------------
  0. 片头：剪辑时放 video/intro/renders/ 里对应的片头视频（例如 HSI-Learning-intro-L01-1080p60.mp4），
     片头最后一帧就是课件封面，接 0.3 秒交叉溶解，直接进入第 1 页。
  1. 第一部分：PPT 讲解。从封面讲到“让代码验证你的判断”那一页。
  2. 第二部分：切到 Jupyter，在 Notebook 里逐个运行讲稿列出的 cell。
  3. 第三部分：切回 PPT，讲最后两页：“停下来，做一次判断”和“结论要有边界”，然后结束。

一次性准备（整套课只做一次，已在你电脑上做过就不要重做）
----------------------------------------------------------------
  在项目根目录用项目自己的 Python 运行：
    .\.venv\Scripts\python.exe scripts/prepare_teaching_artifacts.py
    .\.venv\Scripts\python.exe scripts/prepare_classroom.py
  这两条会训练/准备演示用的模型，结果放在 results/ 里。

  重要：PPT 上的数字（例如 L07 的 OA 0.9507/0.9428、L09 的阈值 0.2238）就是你电脑上这次运行的结果。
  只要不删除 results/，Notebook 现场运行出来的数字就会和 PPT 一致。
  如果删掉 results/ 重新训练，CNN 相关的数字会有小幅变化（不同机器、不同次训练都会变），
  那就要按 slides/README.md 重新导出事实并重建课件，否则讲稿和屏幕会对不上。
  SVM（L02/L03）和原型网络（L08）的结果是确定的，重跑也一样。

每次录制前（每节课都做）
----------------------------------------------------------------
  [ ] PPT：打开 slides/decks/ 里本课的 pptx，放映模式从第 1 页开始。
  [ ] Jupyter：打开本课的 Notebook，右上角确认 kernel 是 “HSI-Learning (.venv)”。
  [ ] 菜单 Kernel → Restart Kernel and Clear Outputs，让输出在镜头前现场生成。
  [ ] 浏览器缩放到 125%～150%（Ctrl + 加号），确认代码和图在录屏里看得清。
  [ ] 关闭微信/QQ/系统通知，桌面上不要有私人文件名。
  [ ] 录屏软件：1920×1080，帧率 30 或 60。

录制后（重要，避免弄坏仓库里的 Notebook）
----------------------------------------------------------------
  课件里的图片是从 Notebook 已保存的输出里提取的。录完以后：
    - 要么直接关闭 Notebook，选择“不保存”；
    - 要么 Run All 跑完整个 Notebook 再保存。
  不要保存一个“清空了输出”或“只跑了一半”的 Notebook。
  如果你在练习环节改了代码（例如把 BATCH_SIZE 改成 3、把 ACCEPTANCE 改成 0.90），录完记得改回去。

讲稿里的数字从哪里来
----------------------------------------------------------------
  - 【屏幕上应看到】的输出，取自你电脑上已经执行并保存的 Notebook（D:\JupyterWorkSpace\HSI-Learning）。
  - 小数点后几位可能因机器不同略有差别，以屏幕为准；讲稿里会提示哪些数字“必须一致”（手算题、形状），
    哪些“可能略有不同”（训练出来的精度）。
  - 讲稿只讲本仓库实际跑出来、或可以手算验证的内容；没有把握的地方，讲稿会让你说“这只是本次运行”。

如果现场出错
----------------------------------------------------------------
  - 先看报错的最后一行；最常见的是 kernel 选错（回到 L00 的思路：先打印 sys.executable）。
  - FileNotFoundError: Run python scripts/prepare_...：说明 results/ 里缺演示模型，按“一次性准备”运行。
  - 录制时出错不要慌，可以停下来剪掉；也可以如实说“这里报错了，我们看看为什么”，这本身就是很好的教学素材。

每课时长：讲稿按 15～25 分钟设计。第一部分（PPT）约占一半，Notebook 实操约占三分之一，收尾 2～3 分钟。
