## 2. 一句话总结

用**少量 3D 卷积层提取谱空联合特征、一层 2D 卷积精炼空间**的混合层级，以低于纯 3D 网络的计算代价同时保住光谱与空间两路信息。

## 3. 问题与缺口

- 纯 2D CNN：patch 内逐通道卷积，光谱维被 PCA 压缩后只能靠层间间接组合，判别细节（吸收谷、红边形状）丢失；
- 纯 3D CNN：谱空联合表达强，但计算贵、参数/层数加深后边际收益递减，且空间判别未必充分；
- 缺口：能否"3D 只做浅层联合、2D 负责深层空间"地各取所长？

## 4. 方法拆解

```
输入 (1, D', 25, 25)                      # D' = PCA 降维后的波段数
├─ Conv3d(1→8,  7×3×3) + ReLU             # 光谱维大核：抓谱形
├─ Conv3d(8→16, 5×3×3) + ReLU             # 逐层收窄光谱核
├─ Conv3d(16→32, 3×3×3) + ReLU            # 光谱维耗尽（D'→3）
├─ view → (96, 23, 23)                    # ★ 枢纽：D′ 并入通道，转 2D
├─ Conv2d(96→64, 3×3) + ReLU              # 标准图像卷积精炼空间
├─ FC 256 → Dropout(0.4) → FC 128 → Dropout(0.4) → FC 类别数
```

- **核心创新点**：3D-2D 特征层级的显式构造（"联合在前、精炼在后"）；
- **实现细节**：无 BatchNorm、无空间 padding（忠于 2020 年前后论文惯例）；PCA 维数是协议的一部分（⚠️ 待核对：原文各数据集的 PCA 维数——常见复现取 15 或 30，本课程两种都跑过）；
- **课程实测补充**（第 8 章表 8-1）：无空间 padding 使空间维 25→23→21→19→17；dense1 一层占全模型 97.7% 参数（4.74M）——flatten 宽度决定参数大户。

## 8. 复现视角（本课程独家数据，第 8 章）

本课程在两个协议下复现了 HybridSN（`scripts/train_hybridsn.py`，单种子）：

| 协议 | OA | AA | Kappa | 备注 |
|---|---:|---:|---:|---|
| B（30/10/60，seed 63466，PCA-15，patch 25） | 99.20 | 99.18 | 0.9909 | 饱和口径：混淆矩阵近全对（Oats 12/12），泄漏 + 高训练率 |
| C（10/10/80，seed 42，PCA-15，patch 25） | 96.66 | 93.28 | 0.9619 | 10% 小样本下 OA/AA 双冠军（对照第 9 章表 9-3） |

复现得到的**论文之外的知识**：
- dense1（flatten 后 4,735,232 参数）占 97.7%——参数大户是 FC 而非卷积，全局平均池化可砍一个数量级（Capstone 候选改动）；
- 协议 B 的 99.20% 是"饱和数字"：混淆矩阵失去诊断力时，模型间的差异被协议吞没。

## 9. 缺点与可扩展点

1. FC 参数爆炸（flatten 18,496 维）→ 全局平均池化 / 1×1 降维（轻量化方向）；
2. 无 BN / 无残差 → 训练动态偏慢（对照第 9 章 SSRN）；
3. 无空间 padding 丢边界一圈信息（影响小，但协议要写明）；
4. 单次运行、无方差报告（时代局限）；
5. PCA 整图拟合（transductive）——严格协议下数字会变。

**可扩展点（Capstone 候选，按工作量排序）**：谱注意力模块插入 3D 阶段（第 8+10 章组合）；分组 1×1 卷积替代 dense1（轻量化）；PCA 拟合范围的受控对比（协议研究）。

## 10. 与我的想法的联系

- 精读后的第一直觉：**"3D 前置 + 2D 后置"是一个可迁移的组合模式**——把 3D 换成 Mamba 扫描、2D 换成 attention，就是一篇 2024 年风格的论文骨架；
- 需要警惕的自我提问：我的改动在**同协议、多种子**下稳定吗？（第 12 章）
