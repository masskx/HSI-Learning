# AI辅助研究：每条建议必须有验证出口

本页配套L00–L10 PPT中的AI操作卡。这里不集成API，不推荐以工具热度替代方法；不生成虚假的AI对话截图。你可以用可访问的助手，但未授权数据、审稿稿件、访问凭证不能上传。

## 通用提示结构

```text
材料边界：仅使用我提供的代码/数据说明/论文片段。
任务：给出[诊断/形状表/协议审计/文字修改]。
证据：每条绑定函数、变量、原文页段或表格行。
不确定：明确unknown；不要补造作者、DOI、指标或运行记录。
输出：建议 + 最小验证命令/断言 + 可能反例。
禁止：执行安装/删除、用test调参、把相关观察改写为因果结论。
```

## 逐课使用与验收

| 课 | AI做什么 | 学生必须自己检查什么 |
|---|---|---|
| L00 | 根据堆栈列排查路径 | kernel/解释器/依赖确实匹配 |
| L01 | 草拟数据卡 | shape/keys实测；波长与单位来自元数据 |
| L02 | 提协议反例 | fit、阈值、模型选择没有偷看test |
| L03 | 提取baseline配置 | 每个值有源码/命令依据，不猜默认等于论文 |
| L04 | 编写patch边界测试 | 期望值由toy数组手算，不由被测函数生成 |
| L05 | 生成shape/RF表 | dummy forward与含pool的独立递推 |
| L06 | 比较论文与实现 | 页/函数证据；教学变体单独标注 |
| L07 | 从错误提出假设 | 真正类别梯度；新实验而非热图解释证明 |
| L08 | 审计few-shot预算 | 类集合、support/query、总标注量与BN策略 |
| L09 | 审计开集阈值 | known val校准，test只报告 |
| L10 | 润色结果段落 | 数字、引用、限制逐句保留，不能新增证据 |

## 把AI错误变成教学练习

给出一个看似流畅但错误的回答，例如“2D卷积只看单通道”“5-shot只训练25个标签”，要求学生用代码/公式构造反例。评分不看提示词长短，而看证据与判断。

## 可用的结果段落要求

先把句子拆为观察、假设解释、限制三栏，再让AI润色。对未做显著性检验的实验，不允许自动添加significant；对自定义损失，不允许归属给原论文；对单次运行，不允许写“普遍优于”。遵循目标期刊/学校的AI使用与披露要求。
