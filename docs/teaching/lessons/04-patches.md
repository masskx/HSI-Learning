## 18 分钟安排

0–2：一张漂亮预测图背后的最高频错误——标签错一个位置；2–6：5×5 toy 图中心切 3×3；6–10：真实边缘像元与 zero padding；10–14：HWC→CHW→batch；14–16：相邻 patch 共享内容；16–18：练习和断言。

## 六页幻灯片

1. 输入邻域，输出中心标签；不是给 patch 每个位置同时监督。
2. radius=(size−1)/2，原坐标 (r,c) 在 padded cube 中变成 (r+p,c+p)。
3. odd size 有唯一中心；零填充不表示场景真有零反射率。
4. `(9,9,12)→(12,9,9)→(B,12,9,9)`；核在哪滑由轴决定。
5. 未标注邻居仍有观测；训练中心和测试中心分离不等于独立 patch。
6. 每个样本自带原位置，预测用位置回填；不要靠易变的 loader 顺序猜坐标。

## 现场与理论对应

先 `np.arange(25).reshape(5,5)` 手算；再打印 patch 中心与原图值的相等断言，边角验证补零。用 GT 仅作监督和显示，不把它作为预测特征。展示原场景框选、patch、中心十字与 batch shape 四件套。

## 练习 / 答案

为什么相邻 9×9 patch 共享 72/81 内容却不意味着总体“泄漏量=89%”？72/81 只针对横向/纵向相邻两个窗口；全数据的重叠要结合采样位置和标签覆盖实测。把 patch 改为 10 应显式报错或定义偶数中心规则，不能默默切 11。

## 科研产出

一份 patch 提取单元测试和输入协议说明，后续模型直接复用。参考 NumPy pad、PyTorch Dataset。图上的“同类标注占比”受未标注区域影响，不等价于真实地物纯度。AI 生成切片后必须检查首末坐标和中心值；本节全程无需训练。
