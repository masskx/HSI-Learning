## 六页幻灯片

1. 研究问题：谱空特征层级如何组合？不是“混合必然更快”。
2. 无 padding：25→23→21→19→17；PCA-15 深度 15→9→5→3。
3. `(N,32,3,19,19)→(N,96,19,19)`，元素数量不变，**维度重排不恢复 PCA 丢掉的信息**。
4. FC 输入 `64*17*17=18496`，首 FC 参数 `18496*256+256`。
5. 论文参数与本仓库参数分别列，种子/划分/PCA 维数不可混用。
6. 假设：全局池化代替 flatten，代价下降是否伴随性能变化？需要受控实验。

## 练习 / 答案

输入 PCA-30 时最后深度为18，而非3，Conv2d 输入通道为576；空间尺寸不随 PCA 变化。`view` 是形状重解释而不是任意轴交换，换轴用 permute 并关注 contiguous。全局池化砍 FC 不等于“无损轻量化”。
