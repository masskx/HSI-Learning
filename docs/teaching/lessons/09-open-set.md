# L09 · 模型能学会说“不知道”吗？（试录二）

目标：区分排序分数、部署阈值、分类与拒识代价。前置 L02/L05，L08 原型概念有帮助但不是必需。notebook 17 定位 `protocol`、`scores`、`calibration`、`evaluation`、`maps`。

## 逐段试录脚本（25 分钟）

**0:00–2:00 开场**：并列显示 GT 与错误高置信度样本，提问：“模型没见过这类，为什么还给出一个已知类名字？”不预告距离一定胜过 MSP。

**2:00–5:00 定义世界**：显示已知/未知 ID 和样本数。口播：“稀有类被留出只是本课的一种教学划分；未知不是背景，也不等于难分类。”指出原始类 ID 与模型连续标签映射。

**5:00–8:00 Softmax 手算**：logits (2,1) 的最大概率约 .731；整体平移不改变概率。说：“归一化没有未知输出槽，但不意味着所有分数方法无效。”

**8:00–12:00 两种分数**：MSP unknown score=1−max softmax；distance=最近训练类原型距离。现场收集一小批特征和同批标签，展示打乱顺序后原型仍一致。不是把 16 章 encoder 偷换进来——本课 encoder 由已知类监督训练。

**12:00–16:00 校准**：只打开 known validation 分数，选95%接受率对应分位数。口播：“到这里阈值已经冻结。测试 GT 此前不能参与选择。”标明这是已知接受率目标，不保证未知召回。

**16:00–20:00 现场推理**：加载可信包，对全图分批生成 MSP/distance map。白色=拒识，黑色=未标注背景，已知类沿用固定颜色。GT 未知区域也用白色，方便对照。

**20:00–23:00 错误图**：显示已知误拒、未知漏检、已知错分。说：“白色越多不一定越好——把所有点拒掉可以有100%未知召回，却没有可用分类。”

**23:00–25:00 总结与练习**：报告拒识前已知精度、拒识后正确接受率、误拒率、未知召回、AUROC。把接受率从.95改为.90，仅用 validation 重新校准，预测变化的方向后再运行。

## 课后题 / 答案

为何 MSP 不需要修改 classifier，但仍可能降低已知类可用准确率？模型本体不变，但阈值会拒绝已知样本，必须报告拒识后指标。阈值取测试已知均值是否合理？不合理，部署前无法使用未来测试标签校准。

OpenMax 只作概念延伸：正确分类训练样本的激活向量、类均值、距离尾部 EVT 拟合、重标定未知质量；不是“拟合误分类样本”。
