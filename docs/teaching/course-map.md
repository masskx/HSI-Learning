主线：基础 → 经典模型 → 少样本 → 开集 → 科研证据。SSRN/Transformer 为专题延伸，不靠新名词堆叠制造进阶感。每节只回答一个主问题；复杂内容拆成上下集而非跳过协议。

## 三层交付

- **快速入口**：问题、关键图、五行结论、运行链接（供检索）。
- **主视频**：约 15–25 分钟的推导—代码—实验—解释，实际时长由试录决定。
- **研究材料**：完整 Notebook、配置、来源、练习答案及局限，支持不看视频独立使用。

## 如何用讲课卡

每张卡同时包含 6 页幻灯片提纲；无需先做复杂动画。录屏时左侧展示图或公式，右侧展示关键 cell。代码定位优先用 cell ID/章节标题，已有旧 notebook 使用唯一函数名，不依赖会漂移的 cell 序号。

## 就绪门禁

逐课检查四个独立状态：`正文核验 / 代码测试 / 输出验收 / 试录通过`。只有四项都有证据才能标“可发布”；本页不是发布认证。参见 [验收清单](recording-checklist.md)、[来源核对](source-audit.md)、[纠错记录](errata.md)。

课程不承诺论文接收或播放量。AI 可用于解释和排查，但原文、测试、独立复现才是证据。
