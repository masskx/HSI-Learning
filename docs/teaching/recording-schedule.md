# 国庆录课弹性安排（2026-10-01 起）

录制依赖“验收通过”，不依赖某天强行达成高分。以下是工作分组而非必须一天录完的产量承诺。

| 时段 | 主任务 | 当天可检验产出 |
|---|---|---|
| 假期前 | 修正核心协议；环境/演示资产验证；试录素材准备 | 测试报告、来源状态、11张讲课卡 |
| 10月1日 | L01 数据与 L09 开集各试录5–10分钟，回放调整 | 两段试录与复盘清单，不急着发布 |
| 10月2日 | L00–L02 基础入口 | 环境、数据、协议三段课程 |
| 10月3日 | L03–L04 基线与 patch | 可运行 baseline、patch 手算演示 |
| 10月4日 | L05–L06 卷积与 HybridSN | shape/公式/代码映射完整 |
| 10月5日 | L07 错误分析、L08 小样本 | 真实 CAM、support/query 演示 |
| 10月6日 | L09 开集、L10 科研证据 | 拒识错误图、实验与写作示范 |
| 剩余假期时间 | 补录、切章节、字幕/链接核查 | 首批发布包；专题后续扩展 |

若时间不足，先完整发布 L00–L04，再发布小样本/开集主线。不要为赶数量删掉校准、数据划分和方法限制。

## 实验与内容并行

实验串行排队、逐任务保留 stdout/stderr，失败立即停止并报告；正文/讲课卡可同步准备。**结果未到时留待验，不把预期写成观察。** 不重复大规模跨数据集对照，只训练修正后演示需要的模型。

## 首批发布结构

每节提供一段快速入口摘要、主视频、完整 Notebook。观众可以先浏览问题与图判断是否需要看全片，也可以直接运行代码。标题为“问题 + 经典方法名”，避免“顶刊必发/全网最强”等不可验证承诺。
